## RULE

Every complete reader-facing Vietnamese sentence starts with an uppercase letter. Apply this to body copy, captions, notes, bullets, table cells, cards, expanded details, tooltips, accessibility text, and dynamically revealed content.

## EXCEPTIONS

Keep lowercase only when it is part of an official identity or machine-readable value: deliberately lowercase brand/proper names, URLs, email addresses, file paths, code, formulas, stable IDs, hexadecimal values, hashtags, and exact source titles.

## EDITING ORDER

1. Correct the canonical content or registry.
2. Rebuild the reader artifact.
3. Activate every tab/state and scan rendered plus accessible text.
4. Use runtime normalization only as a safeguard for dynamic copy.
5. Treat a user screenshot as a blocking regression fixture until the same state is visibly clean.
